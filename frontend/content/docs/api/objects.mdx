import { TypeTable } from 'fumadocs-ui/components/type-table'

TypeScript definitions for all of these live in `frontend/lib/core/types.ts` and can be copied
directly. Some optional fields there (vector `fields`, `filters`, `reused`) belonged to the
original `core/` service and are absent or empty from this backend.

## Upload

<TypeTable
  type={{
    upload_id: { type: 'string', description: '32 hex characters', required: true },

## Chunk

One chunk with whatever each analyzer produced for it, merged onto the same object.

<TypeTable
  type={{
    chunk_id: { type: 'number', required: true },
    start: { type: 'number', required: true },
    end: { type: 'number', required: true },
    timecode: { type: 'string', description: '"m:ss-m:ss"', required: true },
    default_video: { type: '{ description, setting, people[], objects[], actions[], tags[] }' },
    transcript: { type: '{ text }' },
    diarization: { type: '{ text, turns: SpeakerTurn[], speakers: string[] }' },
    ocr: { type: '{ texts: { text, context }[], summary }' },
    people: { type: '{ people: object[], people_count: number, summary }' },
    object_detection: { type: '{ detections: { object }[], objects: string[], summary }' },
  }}
/>

<Callout type="info">
  Only the analyzers with output for that chunk appear as keys. Checking `"ocr" in chunk` is the
  right way to ask whether that pass produced anything for this moment.
</Callout>
