## `GET /health`

Liveness, plus what this instance has loaded. Open — no token required.

```json
{
  "status": "ok",
  "engine": "vidra 3.0.0",
  "tier": "llm",
  "data": "/path/to/backend/data",
  "videos": 1,
  "analyzers": ["default_video", "transcript", "diarization", "ocr", "people", "object_detection"],
  "aggregators": ["chapters", "coverage", "entities", "events", "ner", "object_entities",
                  "sentiment", "speaker_stats", "stats", "summary", "text_entities"],
  "ffmpeg": "/opt/homebrew/bin/ffmpeg"
}
```

| Field | Meaning |
|---|---|
| `status` | Always `ok` when the server answers |
| `engine` | The VIDRA version |
| `tier` | `VIDRA_TIER` — the costliest aggregates an ingest runs |
| `data` | Where everything is written |
| `videos` | How many videos are ingested |
| `analyzers`, `aggregators` | What can be asked for |
| `ffmpeg` | Path to ffmpeg, or `null` if it isn't installed |

<Callout type="info">
  `ffmpeg: null` means ingests will fail. Install it (`brew install ffmpeg` on macOS) and restart.
</Callout>

## `GET /schema`

What the install supports, in one call.

```json
{
  "analyzers": ["default_video", "transcript", "diarization", "ocr", "people", "object_detection"],
  "exclusive_groups": [["diarization", "transcript"]],
  "aggregators": {
    "stats": { "depends_on": [], "uses_llm": false },
    "ner": { "depends_on": [], "uses_llm": false },
    "summary": { "depends_on": [], "uses_llm": true },
    "entities": { "depends_on": [], "uses_llm": true }
  },
  "filters": {}
}
```

| Section | Use |
|---|---|
| `analyzers` | Which passes this install can run |
| `exclusive_groups` | Sets that cannot be selected together, so a client can enforce it |
| `aggregators` | Every aggregate, and whether it bills LLM calls |
| `filters` | Always empty — this backend has no structured search filters |

`depends_on` is always empty here: which analyzer an aggregate needs is listed in
[Aggregators](/docs/concepts/aggregators), and an aggregate whose analyzer is missing is skipped.

## `GET /analyzers`

What an upload form needs.

```json
{
  "analyzers": ["default_video", "transcript", "diarization", "ocr", "people", "object_detection"],
  "fields": ["combined"],
  "exclusive_groups": [["diarization", "transcript"]],
  "descriptions": {
    "default_video": "Describe each chunk's frames with the vision model",
    "transcript": "Whisper transcript of the soundtrack",
    "diarization": "Transcript with speaker turns (Whisper + pyannote)",
    "ocr": "On-screen text, sampled where text appears",
    "people": "People, sampled where YOLO sees them change",
    "object_detection": "Objects, sampled where detections change"
  }
}
```

`exclusive_groups` lists analyzer sets that cannot be selected together, so a client can grey the
option out rather than discovering it as a `400` on submit. `fields` is kept for compatibility;
`combined` is the only value.
