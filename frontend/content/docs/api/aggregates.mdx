## `GET /videos/{video_id}/aggregates`

Video-level results. Pass `?aggregator=summary` for one, or omit for all.

### All

```json
{
  "video_id": "dbf7af7300ab2484",
  "available": ["chapters", "coverage", "events", "ner", "sentiment", "speaker_stats",
                "stats", "summary", "text_entities"],
  "aggregates": { "summary": { "…": "…" }, "chapters": { "…": "…" } }
}
```

### One

```json
{ "video_id": "dbf7af7300ab2484", "aggregator": "summary", "result": { "…": "…" } }
```

<Callout type="warn">
  Requesting an aggregate the video does not have is a **400**, and the message lists what it does
  have — which is exactly the correction a caller needs. `404` is reserved for an unknown video.
</Callout>

### The eleven

| Aggregate | Tier | Needs | Produces |
|---|---|---|---|
| `stats` | free | – | Duration, chunk lengths, frames sampled, words, words per minute |
| `coverage` | free | – | Which chunks have picture, sound, both or neither |
| `speaker_stats` | free | `diarization` | Talk time, share, turns, handovers |
| `ner` | local | – | Named entities in speech and descriptions (GLiNER) |
| `sentiment` | local | – | Sentiment per chunk, mean, turning points (DistilBERT SST-2) |
| `summary` | llm | – | Summary, topics, setting, notable moments |
| `chapters` | llm | – | Titled sections of consecutive chunks |
| `events` | llm | – | Discrete timestamped events |
| `entities` | llm | `people` | People linked across chunks |
| `object_entities` | llm | `object_detection` | Objects linked across chunks |
| `text_entities` | llm | `ocr` | On-screen text linked across chunks |

An aggregate whose analyzer the video lacks is **skipped, not failed**. Which tiers run at ingest
is set by `VIDRA_TIER`. Every time span in these results carries both `start_ts` / `end_ts`
(VIDRA's names) and `start` / `end`.

### Shapes

The examples are from a 5-minute HTML tutorial analysed with `default_video`, `diarization` and
`ocr`.

`summary`

```json
{
  "summary": "The video is a fast-paced visual introduction to modern HTML…",
  "topics": ["HTML document structure and boilerplate", "Elements, tags, headings, paragraphs, and nesting"],
  "setting": "An animated instructional presentation using code-editor and browser examples…",
  "notable": ["Code is repeatedly paired with a browser preview to show how markup renders."],
  "chunks_read": 24,
  "reduction_levels": 0,
  "word_count": 209
}
```

`chapters`

```json
{
  "chapters": [{ "title": "HTML Foundations: From Elements to Page Structure", "summary": "…",
                 "chunk_ids": [0, 1, 2, 3, 4, 5], "start": 0.0, "end": 81.333 }],
  "count": 4,
  "covers_all_chunks": true
}
```

`events`

```json
{
  "events": [{ "what": "An animated introduction presents HTML…", "kind": "change",
               "event": "An animated introduction presents HTML…", "category": "change",
               "chunk_id": 0, "start": 0.0, "end": 13.834 }],
  "count": 36
}
```

`event` and `category` are copies of `what` and `kind`, under the names the frontend reads.

`stats`

```json
{
  "duration_s": 311.433,
  "chunks": 24,
  "chunk_s": { "min": 5.5, "median": 13.834, "max": 19.666 },
  "policy": "scene",
  "frames_sampled": 489,
  "descriptions_by_sampler": { "uniform": 24, "text": 24 },
  "words": 997,
  "chunks_with_speech": 23,
  "words_per_minute": 192.1
}
```

`coverage`

```json
{
  "both": 23, "picture_only": 1, "sound_only": 0, "neither": 0,
  "silent_chunks": [],
  "chunks": [{ "chunk_id": 0, "start": 0.0, "end": 13.834, "sources": ["text", "transcript", "uniform"] }]
}
```

`speaker_stats`

```json
{
  "speakers": [{ "speaker": "SPEAKER_00", "seconds": 299.06, "share": 1.0 }],
  "speaker_count": 1, "turns": 23, "handovers": 0, "monologue": true,
  "speech_s": 299.06, "speech_ratio": 0.9603, "dominant": "SPEAKER_00"
}
```

`ner`

```json
{
  "entities": [{ "text": "Google", "label": "organisation", "chunk_ids": [4, 5, 11, 22], "mentions": 4 }],
  "by_label": { "organisation": 6, "product": 7, "person": 6, "date": 2, "event": 3, "location": 3 },
  "model": "urchade/gliner_small-v2.1"
}
```

`sentiment`

```json
{
  "per_chunk": [{ "chunk_id": 0, "start": 0.0, "end": 13.834, "label": "negative", "score": 0.9835, "signed": -0.9835 }],
  "mean": -0.9278,
  "positive_chunks": 0, "negative_chunks": 24,
  "turning_points": [],
  "model": "distilbert-base-uncased-finetuned-sst-2-english"
}
```

<Callout type="info">
  SST-2 only knows *positive* and *negative*, so neutral speech — like the tutorial above — often
  comes out strongly negative. Read `sentiment` as relative changes within a video, not as an
  absolute verdict.
</Callout>

`entities`, `object_entities`, `text_entities` — see [Entities](/docs/api/entities).

## `POST /videos/{video_id}/aggregates`

Re-run aggregates over already-analysed output. Returns **202** and a `job_id` to poll.

| Param | In | Type | Default | Notes |
|---|---|---|---|---|
| `aggregators` | form | string | everything up to `VIDRA_TIER` | Comma-separated names |
| `force` | query | bool | `true` | Recompute even when already stored |

```bash
curl -X POST "http://127.0.0.1:8077/videos/dbf7af7300ab2484/aggregates?force=true" \
  -H "X-Core-Token: $TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data "aggregators=summary,chapters"
```

```json
{ "job_id": "9f2c1a77b410", "status": "queued", "video_id": "dbf7af7300ab2484" }
```

### Job result

```json
{
  "video_id": "dbf7af7300ab2484",
  "ran": ["summary", "chapters"],
  "aggregates": ["chapters", "coverage", "events", "ner", "sentiment", "speaker_stats",
                 "stats", "summary", "text_entities"],
  "skipped": {}
}
```

| Field | Meaning |
|---|---|
| `ran` | The aggregates handed their inputs this time |
| `aggregates` | Everything now stored for the video |
| `skipped` | `{name: reason}` for each one this video can't satisfy — for example `entities` without the `people` analyzer |

<Callout type="info">
  Aggregates read stored chunk output rather than the video, so this costs **no re-analysis** —
  only the LLM calls for the `llm`-tier ones.
</Callout>

### Errors

| Code | Cause |
|---|---|
| `404` | Unknown video |

An unknown aggregate name fails the job rather than the request.
