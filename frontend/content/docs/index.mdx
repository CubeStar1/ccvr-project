**FalconVQA** — *Fast Augmented Language-based CONversational Video Question Answering* — is
**retrieval-augmented generation for video**. Point it at footage and it splits the video into
chunks, transcribes the soundtrack, describes what is on screen, rolls those results up into
video-level insight, and indexes all of it so the whole thing can be searched or asked questions
of.

```
video ─▶ listen ─▶ chunk ─▶ sample frames ─▶ describe ─▶ embed ─▶ aggregate ─▶ search / ask
```

Every answer is grounded in a specific moment. Nothing is answered from the model's memory —
if a claim is not in a retrieved chunk or a stored video-level result, it does not get made.

The frontend reaches the backend only through `frontend/lib/core/client.ts`, over the HTTP API
documented under [API Reference](/docs/api). The backend's routes and response shapes were kept
from the original `core/` service, so the frontend did not have to change to switch engines.

## What it can answer

| You ask | What runs |
|---|---|
| "Summarise this video" / "What is this about?" | `ask_video` → moments plus the `summary` and `chapters` aggregates |
| "Find the part where they discuss pricing" | `search_moments` → hybrid search over chunk descriptions and transcript |
| "Show me every clip of the man in yellow shorts" | search → `show_clips` → the artifact panel |
| "What exactly was said at 2:30?" | `get_video_transcript` → speech lines, attributed when diarized |
| "How long is it, how much talking is there?" | `get_video_insights` with `stats` |
| "What happened, in order?" | `get_video_insights` with `events` or `chapters` |
| "Which brands or names come up?" | `get_video_insights` with `ner` |
| "Who was in this, and what did each person do?" | `get_video_entities` → people linked across the whole video |

  />
  <Card
    title="Hybrid retrieval"

  />
</Cards>

<Callout type="info">
  Speech recognition (Whisper), speaker diarization (pyannote), frame sampling (OpenCV, YOLO,
  CLIP), named entities (GLiNER) and sentiment (DistilBERT) run on your own machine. Frame
  descriptions, embeddings and the written aggregates are OpenAI API calls — selected frames and
  text leave the machine; the video file does not.
</Callout>
