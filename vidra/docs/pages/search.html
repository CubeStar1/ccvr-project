Search

Find the chunks that match a text query.

Searching

from vidra import Folder, LocalEmbedder, Models
from vidra.video_rag import search

models = Models(embedder=LocalEmbedder())      # the embedder that built the index
db = Folder("data/out")                         # or Supabase()

moments, notes = search("a customer paying in cash", "shop", models=models, database=db)
for m in moments:
    print(m.video_id, m.chunk_id, m.start_ts, m.end_ts, round(m.score, 4))
    for hit in m.hits:                          # the answers that matched in this chunk
        print("   ", hit["sampler_id"], hit["content"][:80])

Search reads the database the run exported to, or a Folder over the output. Use the embedder that built the index; other embedders' vectors are ignored.

Arguments

search(query, video_id=None, moments=5, sampler=None, candidates=20, question=None, strategy=None, chunk_ids=None, window=0, after=None, before=None, structured=None, grids=None, database=None, models=None) -> (list[Moment], list[str])
ArgumentDefaultMeaning
queryrequiredThe text to find; empty is refused.
video_idevery videoOne id, or a list of ids.
modelsevery defaultA Models; only two roles are used. Its embedder (default OpenAIEmbedder()) must be the one the index was built with. Its visual_embedder also searches the frames glance embedded, in their own ranking; given alone, only the frames are searched.
databaseSupabase()Where to search: a built Database.
moments5How many chunks to return.
candidates20Units ranked before grouping into chunks. Raise it if filters or many samplers leave too few moments.
questionnoneOnly this question's answers, from any sampler: "text" matches clip:text and uniform:text.
samplernoneOnly this answer id: "clip:text", "yolo", "transcript".
strategynoneOnly this sampler's answers, any question: "clip".
structurednoneExact field values: {"payment": "cash"}. A list field matches if it contains the value.
chunk_idsnoneOnly these chunks.
after, beforenoneOnly chunks overlapping this window, in seconds.
window0With chunk_ids or after/before: widen by this many chunks each side.
gridsnone{video_id: timeline.json path}: read chunk times from the file, not the database.
# only what was read off the screen, between minute 2 and minute 5
search("the error message", "talk", question="text", after=120, before=300,
       models=models, database=db)

# only clip's answers to the checkout question, where a card was used
search("paying", "shop", sampler="clip:checkout", structured={"payment": "card"},
       models=models, database=db)

# across two videos
search("a forklift reversing", ["monday", "tuesday"], moments=10,
       models=models, database=db)

What comes back

search returns a list of Moment objects, best first, and a list of notes.

MomentIs
video_idWhich video.
chunk_idWhich chunk of that video.
start_ts, end_tsThe chunk's start and end, in seconds.
scoreA score for ordering results. It is not a similarity (see ranking).
hitsThe matching answers in this chunk, best first.
samplersThe answer ids of the hits.
as_dict()The moment as plain data.

Each hit has sampler_id (the answer id), sampler, question, content (the embedded text), structured (the fields), dense_rank (vector rank) and text_rank (full-text rank, or None).

If the results are empty or look wrong, check the notes; they report, for example, when filters removed most candidates. If nothing is indexed for this embedder, search raises MissingArtifact, a FileNotFoundError.

How ranking works

  1. The query is embedded with the embedder's embed_query.
  2. The database ranks candidates units under that embedder, after filters. Supabase fuses vector and Postgres full-text rankings by reciprocal rank; Folder uses vectors only.
  3. Units are grouped by chunk, and a chunk scores 1/(10 + best) + 0.5/(10 + second) from the ranks of its two best units.

Getting better results

  • Describe the moment: "a man hands the cashier a banknote" beats "cash payment".
  • Running several samplers gives each chunk several descriptions, and a chunk that matches in more than one ranks higher.
  • For exact filtering, add a question with a one_of field and use structured= (fields).
  • Use Supabase for names, numbers and exact phrases; Folder has no full-text search.

Searching summaries, chapters and people

To find a video by its summary, a chapter, or a linked person or object, use aggregates.search.
