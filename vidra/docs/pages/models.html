Models

The four model roles, the ready-made classes, and writing your own.

Roles

RoleBase classUsed byDefault
vlmVLMdescribe: frames in, an answer outOpenAI("gpt-6-luna")
llmLLMthe llm aggregators: summary, chapters, events, custom prompts, entity accountsOpenAI("gpt-6-luna")
embedderEmbedderembed, search, chapter boundaries, entity linkingOpenAIEmbedder("text-embedding-3-small")
visual_embedderVisualEmbedderglance: frames in, a vector out, no answer; search over those vectorsnone: frames are not embedded

A role left unset uses its default, except visual_embedder, which has none. Each role has its own base class, so each can be a different model; a class that subclasses two of them, such as VLM and LLM, can fill either role.

Models

Models(vlm=None, llm=None, embedder=None, visual_embedder=None)
from vidra import Anthropic, LocalEmbedder, Models, OpenAI

models = Models(vlm=OpenAI("gpt-6-luna"), llm=Anthropic("claude-haiku-4-5"),
                embedder=LocalEmbedder())

video_rag("shop.mp4", "data/out", models=models)          # uses vlm and embedder
aggregates.aggregate(out=..., models=models, summary=...)  # uses llm and embedder
search("a customer paying", "shop", models=models)         # uses embedder

Build one Models and pass it everywhere, so indexing and search use the same embedder. Each model is checked on construction for the right class, a key, and its own problems() such as a missing API key.

Pipelines and searches (video_rag, video_rag_live, workflow, aggregates.aggregate, search, search_observations, aggregates.search) take models=. A single stage takes the one model it calls: describe(vlm=), embed(embedder=), glance(visual_embedder=), aggregates.summary(llm=). models.resolved() fills in the defaults.

Anthropic

Anthropic(model="claude-haiku-4-5", api_key=None, base_url="https://api.anthropic.com", concurrency=8, client=None)

As OpenAI, except that client is an httpx.AsyncClient, api_key defaults to ANTHROPIC_API_KEY and the key is anthropic:<model>. Rate-limit and server errors are retried twice.

Chat

Chat(model, base_url, name="chat", api_key=None, structured="json_schema", token_field="max_tokens", concurrency=8, client=None)

Works with any server that implements OpenAI's Chat Completions API, such as Ollama, LM Studio, vLLM or llama.cpp.

ArgumentMeaning
modelThe model id the server knows.
base_urlThe API root, usually ending in /v1.
nameFirst part of the key (<name>:<model>), to tell servers apart.
api_keyOptional for local servers.
structuredHow structure is enforced: "json_schema" (by the server), "json_object" (any JSON), or "prompt" (schema in the prompt). Use a weaker mode if the server rejects JSON Schema.
token_fieldThe name of the output-length parameter, max_tokens or max_completion_tokens. If the server rejects it, the call is retried with the other.
concurrencyCalls in flight; 1 for single-request servers.
clientA ready openai.AsyncOpenAI.
import os
from vidra import Chat

vlm = Chat("gpt-6-luna", base_url="https://api.openai.com/v1", name="openai-chat",
           api_key=os.environ["OPENAI_API_KEY"])

Stub

Stub() returns placeholder answers in the requested shape, for tests or running without an API key. Its key is stub.

OpenAIEmbedder

OpenAIEmbedder(model="text-embedding-3-small", api_key=None, base_url=None, name="openai", dims=None, input_type=False, query_prefix=None, document_prefix=None, client=None)
ArgumentMeaning
modelThe embedding model.
api_keyDefault OPENAI_API_KEY; optional with base_url.
base_urlAnother server with an OpenAI-style /embeddings.
nameThe first part of the key: openai:text-embedding-3-small:1536.
dimsRequested width (sent as dimensions).
input_typeSend query/document with each call (e.g. Voyage).
query_prefix, document_prefixText before each query or passage. Known models get theirs automatically; setting one changes the key.

The vector width is part of the key; for non-OpenAI models it is found with one call per process.

LocalEmbedder

LocalEmbedder(model="BAAI/bge-small-en-v1.5", dims=None, device=None, batch=32, query_prefix=None, document_prefix=None)
ArgumentMeaning
modelA sentence-transformers model on Hugging Face, downloaded on first use.
dimsExpected width; checked.
deviceDefault: cuda, then mps, then the CPU.
batchTexts per forward pass.
query_prefix, document_prefixAs for OpenAIEmbedder; e5, nomic, bge and mxbai get theirs automatically.

Requires vidra[local]. Its key is local:<model>:<width>. The default model searches about as well as text-embedding-3-small and embeds a query in milliseconds.

HashEmbedder

HashEmbedder(dims=256) hashes words into vectors, with no model or network; it matches exact words only, so use it for tests. Its key is hash:none:<dims>.

LocalVisualEmbedder

LocalVisualEmbedder(model="openai/clip-vit-base-patch32", device=None, batch=32)
ArgumentMeaning
modelA CLIP or SigLIP checkpoint on Hugging Face, e.g. "google/siglip2-base-patch16-224".
deviceDefault: cuda, then mps, then the CPU.
batchImages per forward pass.

Requires vidra[local]. A unit's images are embedded one at a time and averaged, so the key is local:<model>:<width>:mean. Queries are truncated to 77 tokens for CLIP and 64 for SigLIP. SigLIP 2 gives much better results than CLIP ViT-B/32.

LocalMultimodalEmbedder

LocalMultimodalEmbedder(model="google/embeddinggemma-2", dims=None, device=None, batch=8, query_prompt="SearchQuery", document_prompt="Document")
ArgumentMeaning
modelA sentence-transformers model that embeds text and images together.
dimsShorter vectors: 768, 512, 256 or 128 for EmbeddingGemma 2. Part of the key.
deviceDefault: cuda, then mps, then the CPU; bfloat16 on a GPU that has it.
batchInputs per forward pass.
query_prompt, document_promptThe model's own prompt names for a search and for a passage.
from vidra import LocalMultimodalEmbedder, Models

gemma = LocalMultimodalEmbedder()
models = Models(vlm=OpenAI(), embedder=gemma, visual_embedder=gemma)

Embeds a unit's frames and labelled views as one input, up to 29 images (max_images). It can fill either role or both; image vectors are stored under the key plus :images, apart from text vectors. Requires sentence-transformers>=6.1 and transformers>=5.18, newer than vidra[local] installs.

Writing your own

Subclass a role's base class, set key, and implement its method, either as an async def or a plain def.

from vidra import Embedder, LLM, VLM, VisualEmbedder

class MyVLM(VLM):
    key = "mylab:vision-v2"

    async def generate(self, parts, schema=None, system=None, max_output_tokens=4000):
        ...
        return {"summary": "...", "setting": "..."}   # a dict, or its JSON text

class MyLLM(LLM):
    key = "mylab:text-v1"

    def complete(self, prompt, schema=None, system=None, max_output_tokens=4000):
        ...
        return "..."                                    # text, or a dict for a schema

class MyEmbedder(Embedder):
    key = "mylab:embed-v1:768"

    def embed(self, texts):
        ...
        return [[0.0] * 768 for _ in texts]             # one vector per text, one width

class MyVisualEmbedder(VisualEmbedder):
    key = "mylab:see-v1:512"
    max_images = 8                                      # refused before work above this

    def embed_images(self, groups):
        ...
        return [[0.0] * 512 for _ in groups]            # one vector per group of parts

    def embed_query(self, text):
        ...
        return [0.0] * 512                              # a search, in the same space

VLM.generate

generate(parts, schema=None, system=None, max_output_tokens=4000)
ArgumentIs
partsThe request in order: the instruction, then a label and image per frame. Each part is {"type": "text", "text": str} or {"type": "image", "data": bytes, "mime": "image/jpeg"}.
schema{"name": str, "schema": dict}, a strict JSON Schema to match, or None for prose.
systemThe system prompt, or None.
max_output_tokensAnswer length cap.

Return a dict matching the schema, or a JSON string. Without a schema, return text.

LLM.complete

complete(prompt, schema=None, system=None, max_output_tokens=4000)

prompt is a string; everything else is as for generate.

Embedder.embed and embed_query

embed(texts) -> list[list[float]] embed_query(text) -> list[float]

embed(texts) returns one vector per text, all of the same width. embed_query(text) embeds a search query; by default it returns embed([text])[0].

VisualEmbedder.embed_images and embed_query

embed_images(groups) -> list[list[float]] embed_query(text) -> list[float]

embed_images(groups) returns one vector per group. A group is one unit's images as parts in VLM.generate's format: an {"type": "image", "data": bytes, ...} part per frame or view, each view preceded by a {"type": "text", "text": label} part. A one-image model must combine a group itself, for example by averaging. embed_query(text) embeds a query in the same space and has no default. max_images (default None) caps the images per group, checked before any is read.

Attributes and checks

MemberMeaning
keyRequired. Identifies the model (see Keys). May be a property.
concurrencyThe number of calls in flight at once. Default 8.
problems()A list of reasons the model can't run, such as a missing key. Checked before any work starts; the first is raised as ModelUnavailable.
name, modelRead-only. The parts of key before and after the first colon. Store your own client or weights under other names, such as self.client.

Keys

The key is stored with every answer and vector, and determines what is reused:

  • Change the key when the model changes; otherwise the old model's answers are reused.
  • For an embedder, the key identifies the vector space, so include the width (mylab:embed-v1:768).
  • Keep the key the same while the model is unchanged; otherwise everything is recomputed.

How your method is called

  • At most concurrency calls run at once on each instance.
  • A plain def method is run in a thread.
  • When a schema was requested, a JSON string answer is parsed, and an answer that is not an object is refused.
  • Exceptions are re-raised as ModelFailed with the model's key. Implement retries in your method if you need them.

Errors

ClassRaised when
Refuseda model is the wrong class for its role (vlm must be a VLM, not MyLLM) or has no key
vidra.ModelUnavailablea model reports a problem (no key) before work, or a local model won't load
ModelFaileda call failed: refusal, network error, wrong shape (vidra.shared.models.base.ModelFailed)

All three are VidraErrors; the last two are vidra.Unavailable.

Complete example

A VLM and LLM calling the OpenAI SDK directly, and an embedder using sentence-transformers.

docs/pages/examples/custom_models.py
"""Models of your own: subclass VLM, LLM or Embedder and fill in one method.

These three wrap the OpenAI SDK and sentence-transformers directly, to show
what a method receives and must return; any other client works the same way.

    python custom_models.py path/to/video.mp4
"""

import base64
import os
import sys

import vidra
from vidra import LLM, VLM, Embedder, Folder, Models, aggregates
from vidra.video_rag import search, video_rag
from vidra.video_rag.samplers import Clip

vidra.configure(env_file=".env")


def json_format(schema):
    """`schema` is {"name": ..., "schema": <JSON Schema>}, or None for prose."""
    if schema is None:
        return {}
    return {"response_format": {"type": "json_schema",
                                "json_schema": {**schema, "strict": True}}}


class MyVLM(VLM):
    """Describes frames. `generate` may be async, as here, or a plain def."""

    key = "mine:gpt-6-luna"       # the identity stored with every answer
    concurrency = 4                 # calls in flight at once

    def __init__(self):
        from openai import AsyncOpenAI
        self.client = AsyncOpenAI()

    def problems(self):
        # Checked before any work starts, so a missing key fails at once.
        return [] if os.environ.get("OPENAI_API_KEY") else ["OPENAI_API_KEY is not set"]

    async def generate(self, parts, schema=None, system=None, max_output_tokens=4000):
        # parts: {"type": "text", "text": ...} and
        #        {"type": "image", "data": <bytes>, "mime": "image/jpeg"}, in order.
        content = []
        for part in parts:
            if part["type"] == "text":
                content.append({"type": "text", "text": part["text"]})
            else:
                data = base64.b64encode(part["data"]).decode()
                content.append({"type": "image_url",
                                "image_url": {"url": f"data:{part['mime']};base64,{data}"}})
        messages = ([{"role": "system", "content": system}] if system else [])
        messages.append({"role": "user", "content": content})
        response = await self.client.chat.completions.create(
            model="gpt-6-luna", messages=messages,
            max_completion_tokens=max_output_tokens, **json_format(schema))
        return response.choices[0].message.content    # JSON text is parsed for you


class MyLLM(LLM):
    """Writes summaries, chapters, events and entity accounts. A plain def runs
    in a thread."""

    key = "mine:gpt-6-luna"

    def __init__(self):
        from openai import OpenAI
        self.client = OpenAI()

    def complete(self, prompt, schema=None, system=None, max_output_tokens=4000):
        messages = ([{"role": "system", "content": system}] if system else [])
        messages.append({"role": "user", "content": prompt})
        response = self.client.chat.completions.create(
            model="gpt-6-luna", messages=messages,
            max_completion_tokens=max_output_tokens, **json_format(schema))
        return response.choices[0].message.content


class MyEmbedder(Embedder):
    """Text to vectors. The key names the vector space: include the width."""

    key = "mine:all-MiniLM-L6-v2:384"

    def __init__(self):
        from sentence_transformers import SentenceTransformer
        self.encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

    def embed(self, texts):
        return self.encoder.encode(list(texts), normalize_embeddings=True).tolist()

    # Override embed_query only when a query is embedded differently.


models = Models(vlm=MyVLM(), llm=MyLLM(), embedder=MyEmbedder())
database = Folder("data/out")

run = video_rag(sys.argv[1], "data/out", sampler=Clip(), use_audio=False,
                models=models, database=database)
moments, _ = search("people at a counter", run.video_id, models=models, database=database)
print([(m.chunk_id, round(m.start_ts, 1)) for m in moments])

d = run.folder
video = aggregates.record(timeline=d / "timeline.json", descriptions=d / "descriptions.json")
aggregates.summary(input=video.excerpt(answers={"clip": ["summary"]}),
                   out=d / "answers" / "summary.json", llm=models.llm)
print(aggregates.load(d / "answers" / "summary.json").stats["model"])   # mine:gpt-6-luna
