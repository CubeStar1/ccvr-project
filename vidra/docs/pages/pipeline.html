The pipeline

video_rag() runs every stage on one video. workflow runs it, then the aggregators.

video_rag()

from vidra.video_rag import video_rag video_rag(source, into, video_id=None, on_conflict="new", name=None, recorded_at=None, policy="uniform", use_video=True, use_audio=True, sampler=None, models=None, describe=True, resume=True, database=None, on_step=None) -> Run
from vidra import LocalEmbedder, Models, OpenAI, Supabase
from vidra.video_rag import video_rag
from vidra.video_rag.samplers import Clip, Yolo

models = Models(vlm=OpenAI("gpt-6-luna"), embedder=LocalEmbedder())
run = video_rag("shop.mp4", "data/out", policy="scene", sampler=[Clip(), Yolo()],
                models=models, database=Supabase())

video_idfilename stemThe folder name (Video ids).
on_conflict"new"If a different file holds the id: "new" mints shop-2, "replace" deletes the old folder, "refuse" raises media.VideoIdTaken.
namethe filenameDisplay name, stored in media.json; kept by later runs that omit it.
recorded_atcontainer tagsRecording time, a datetime or ISO 8601 string; kept by later runs that omit it.
policy"uniform"Where chunks are cut: uniform, scene, vad, speaker (the grid).
use_videoTrueRead the picture (video and describe).
use_audioTrueRead the soundtrack (audio and cut). Needs vidra[audio].
samplerUniform()Which frames to keep and what to ask: a sampler object or a list of them, e.g. [Clip(), Yolo(prompts=["overview"])], each with its own settings (Samplers).
modelsevery defaultA Models: the vlm (default OpenAI()), the embedder (default OpenAIEmbedder(); search must use the same one), and the visual_embedder (none: frames are not embedded; with one, the kept frames are embedded too, by glance).
resumeTrueReuse still-current descriptions and vectors. False redoes them.
databasenoneWhere to copy every artifact: a built Database, e.g. Supabase() or Folder("data/out").
on_stepnoneProgress callback (below).
describeTrueAsk the vision model about the kept frames. False needs a visual_embedder: no vision model is called and no text is made from the picture.
from vidra import LocalVisualEmbedder, Models

# embed the frames directly, with no vision model: cheaper, but weaker on actions and text
seen = Models(visual_embedder=LocalVisualEmbedder("google/siglip2-base-patch16-224"))
video_rag("shop.mp4", "data/out", sampler=Clip(), use_audio=False, models=seen,
          describe=False)

The policy, samplers, questions, models and database are checked before the first stage runs. All problems found are raised together as one Refused.

Run

video_rag() returns a Run:

AttributeIs
video_idThe id used, which may differ from the one asked for.
folderThe video's folder, a Path.
stepsEach stage's receipt (Produced), in order: .component, .artifacts, .stats, .skipped.
skipped{stage: why} for stages that did not run.
problemsFailed database writes. The files are still written.
artifacts(){artifact: path} for every file in the folder.
as_dict()The run as plain data.
run.video_id                  # "shop"
run.folder                    # Path("data/out/shop")
run.artifacts()               # {"descriptions": ".../descriptions.json", ...}
run.skipped                   # {"audio": "the file carries no audio stream"}
for step in run.steps:
    print(step.component, step.stats)

What runs, in what order

The stages run in this order, depending on the policy:

PolicyOrder
uniformmedia, audio, boundaries, video, cut, describe, glance (with a visual_embedder), embed
scenemedia, audio, boundaries.evidence (decodes the picture), boundaries, video, cut, describe, embed
vad, speakermedia, audio, boundaries.evidence (reads the transcript), boundaries, video, cut, describe, embed

A stage that doesn't apply, such as audio on a silent file, is skipped with the reason in run.skipped. Each stage runs with its defaults (Whisper small, scene threshold 27, 5 to 20 s chunks, one frame per second); to change them, call the stages directly.

Progress: on_step

on_step(component, produced) is called before each stage with None and after it with its Produced. A callback with a third parameter also gets a Progress for each unit of work in video, describe and embed:

def on_step(component, produced, progress=None):
    if progress is not None:
        print(f"  {component} {progress.completed}/{progress.total} "
              f"({progress.skipped} reused) {progress.current}")
    elif produced is None:
        print("start", component)
    else:
        print("done ", component, produced.stats)

video_rag("shop.mp4", "data/out", sampler=Clip(), on_step=on_step)

Progress has component, total, completed, skipped, current (for example 3:clip) and result. describe reports calls as they finish. Raising in the callback stops the run.

validate

validate takes the same arguments as video_rag(), except on_step, and returns a list of the problems the run would be refused for, without running anything.

from vidra.video_rag import validate, video_rag

problems = validate("shop.mp4", "data/out", policy="scene", sampler=Clip(), models=models)
if not problems:
    run = video_rag("shop.mp4", "data/out", policy="scene", sampler=Clip(), models=models)

layout()

layout(folder) returns the path of every artifact in a video's folder:

from vidra.video_rag import layout

at = layout("data/out/shop")
at["timeline"]          # Path("data/out/shop/timeline.json")
at["store"]             # Path("data/out/shop/store")

workflow: both tiers

workflow.workflow runs video_rag, then every aggregator up to a cost tier. Answers are written to <folder>/aggregates/ and reused while current.

from vidra import LocalEmbedder, Models, OpenAI, Supabase, workflow

run = workflow.workflow("shop.mp4", sampler=[Clip(), Yolo()], policy="scene", tier="llm",
                        models=Models(vlm=OpenAI(), llm=OpenAI(), embedder=LocalEmbedder()),
                        database=Supabase())

answers = run.steps[-1]                   # the aggregate step's receipt
answers.artifacts                         # {"summary": ".../aggregates/summary.json", ...}
answers.stats["skipped"]                  # {"speakers": "...", ...}
workflow.workflow(source, into=None, video_id=None, name=None, recorded_at=None, policy="uniform", use_video=True, use_audio=True, sampler=None, models=None, describe=True, tier="free", database=None, on_step=None) -> Run

It takes the same arguments as video_rag(), with these differences:

ArgumentDefaultMeaning
intothe data root's out/The parent folder, as in video_rag(), but optional.
modelsevery defaultAs in video_rag(), and its llm (default OpenAI()) answers the llm tier.
tier"free"The costliest tier to run: free, local or llm.
TierRunsEach reads
freestats, coverage, speakersthe record
localthe above, ner, sentimentthe transcript and every answer's prose
llmthe above, summary, chapters, events, every custom prompt, and every linking profile (entities:people, entities:objects, entities:text, custom ones)prompts: the transcript and every answer's prose; profiles: every answer

An aggregator with nothing to read, such as speakers on a silent video, is skipped with the reason. To choose inputs yourself, call the aggregates directly. workflow.validate(...) works like validate and also checks the LLM key. on_step reports "aggregate" last, and workflow.Run is a Run whose last step is the aggregate step.
