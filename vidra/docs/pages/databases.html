Databases

Where runs copy their output and searches read from: Supabase, a folder, or your own class.

Choosing one

DatabaseKeepsSearchNeeds
Supabase()every artifact and answer, as Postgres rowshybrid: vectors and full text, fuseda Supabase project with the schema installed
Folder(root)nothing; reads the output folder in placevectors onlynothing
your own Database subclasswhatever its hooks keepwhatever its read hooks doyour code

Pass it as database= to video_rag, workflow, aggregates.aggregate, search and aggregates.search; a search given none uses Supabase(). A Database is a context manager that calls close() on exit.

Supabase

Supabase(url=None, key=None, read_key=None)
ArgumentDefaultMeaning
urlSUPABASE_URLThe project URL.
keySUPABASE_SECRET_KEYSecret key, for writes.
read_keySUPABASE_PUBLISHABLE_KEYPublishable key, for searches.

The client connects on first use. To set up a Supabase project:

  1. In the SQL editor, run db/supabase/video_rag.sql, then db/supabase/aggregates.sql. This creates the vidra schema: vr_ tables for moments, ag_ tables for aggregates, and the search functions.
  2. Add vidra under Settings → API → Exposed schemas. Otherwise requests fail with PGRST106.
  3. Put the URL and keys in .env, or pass them in code.

Search combines vector similarity with Postgres full-text search. db/supabase/reset.sql drops every VIDRA table, and db/wipe.py deletes videos locally and in Supabase.

Folder

Folder(root=None)

Searches <root>/<video_id>/ in place by cosine similarity; root defaults to the data root's out/. Pointed at the run's output folder, it copies nothing:

db = Folder("data/out")
run = video_rag("shop.mp4", "data/out", models=models, database=db)
search("a customer paying", run.video_id, models=models, database=db)

Aggregate vectors are stored in the source's aggregate_units.json. Folder suits one machine and a few hundred videos; without full-text search, exact names and numbers rank lower than on Supabase.

Writing your own

Subclass Database and implement only the hooks you need. Write hooks you don't implement do nothing, and that artifact is not read or copied. Read hooks you don't implement raise Unsupported, which is both an Unavailable and a NotImplementedError.

from vidra import Database

class VectorsOnly(Database):
    name = "vectors"

    def write_embedded(self, video_id, document):
        for unit in document["units"]:
            my_index.upsert(id=f"{video_id}/{unit['chunk_id']}/{unit['sampler_id']}",
                            vector=unit["vector"],
                            metadata={**unit, "video_id": video_id,
                                      "embedder": document["embedder"]})

video_rag("shop.mp4", "data/out", database=VectorsOnly(), models=models)

A hook that raises is recorded, under your name, in run.problems (or stats["problems"] for aggregates), and the run continues. db.implements("write_embedded") says whether a hook is implemented.

When each hook is called

  1. video_rag, workflow: after each stage, write_<artifact>(video_id, document) per file written, with its JSON as a dict. After describe, also write_prompts(rows).
  2. aggregates.aggregate(database=...), workflow: write_source once (if it fails, nothing else is written), write_answer for each answer, write_definitions once, then write_aggregate_units once. Aggregate vectors are only computed when write_aggregate_units is implemented.
  3. search: search(...). spans(video_id) is called only for a time filter or window (unless grids= is given), or for a hit without start_ts/end_ts. video_ids() is called only for a time filter when no video is named.
  4. aggregates.search: search_aggregates(...).
  5. video_rag_live: write_media when the stream opens, before the duration is known; write_observations(video_id, rows) as answers arrive, with any backlog sent in one call; and the other documents when the stream ends.
  6. search_observations: search_observations(...).

video_rag write hooks

Each hook receives the video id and the document as a dict, as in its JSON file (fields).

HookReceives
write_media(video_id, document)media.json: path, container_format, duration_s, video and audio streams, source (a fingerprint of the file), name, recorded_at
write_raw_transcript(video_id, document)transcript.raw.json: segments, words and turns with times and speakers, speakers, model, track, stats
write_cuts(video_id, document)cuts.json: cuts (times), scores, source, detector, params, stats
write_timeline(video_id, document)timeline.json: chunks (each chunk_id, start_ts, end_ts), policy, params, fingerprint, duration_s, chunk_count
write_manifest(video_id, document)manifest.json: chunks (each with samplers: {sampler: {frame_count, frames}}), source, config, stats
write_transcript(video_id, document)transcript.json: chunks (each chunk_id, text, word_count, turns, structured.speakers)
write_descriptions(video_id, document)descriptions.json: chunks (each with samplers: {answer_id: {sampler, question, description, structured, frame_indexes, ...}}), model
write_embedded(video_id, document)embedded.json: embedder (the key) and units, each with chunk_id, sampler_id, sampler, question, content, structured, text_hash, vector
write_glances(video_id, document)glances.json, in embedded.json's shape: embedder is the visual embedder's key plus :images, content is empty, question is image, structured holds the frames. Supabase stores it like write_embedded; the different key keeps the two sets of rows apart.
write_prompts(rows)the questions a describe run asked: each name, version (the hash stored with its answers), instruction, shape, summary, builtin, about
write_observations(video_id, rows)a live run's answers, in batches, many times per run. Each row is one kept frame and question, with chunk_id, sampler_id, sampler, question, frame_index, media_ts, frames, description, structured, content, text_hash, seen_at, answered_at, lag_s, gap_before, embedder, vector. Key rows by (video_id, sampler_id, frame_index, embedder).

For search to work, implement at least write_timeline and write_embedded, or pass grids= to search instead of storing timelines.

aggregates write hooks

A source is what answers are about: one video, or several combined. source_id is the record's video id.

HookReceives
write_source(source)source_id, video_ids, members (each video_id, first_chunk, chunk_count, offset_s: where it sits on the combined clock), duration_s, chunk_count
write_answer(source_id, answer, items, mentions)answer: aggregate_id, aggregator, tier, payload (whole), inputs, model, version, inputs_fingerprint.
items: what the answer places in time (a chapter, an event, a name ner found, a linked entity), each item_id, item_kind, label, text, chunk_ids, start_ts, end_ts, data.
mentions: for a linked entity, each sighting: item_id, mention_key, chunk_id, sampler_id, entry, doubt. Empty otherwise.
write_definitions(rows)each prompt or profile used: name, version, kind, definition (the entry as stored), builtin
write_aggregate_units(source_id, units, embedder_key)the embedded summary, chapters and entity accounts, each aggregate_id, item_id (empty for a summary), level (source, span or entity), content, start_ts, end_ts, text_hash, vector. These are only computed when this hook is implemented.

Every run sends every answer again, including reused ones, so replace what you hold for that source_id and aggregate_id.

Read hooks

Only search uses the read hooks.

video_ids()

Return every stored video id, as a list. Used when a search names no video.

spans(video_id)

Return the chunks as [(start_ts, end_ts), ...], indexed by chunk id. Used for after/before, window, and hits without times.

search(...)

search(vector, query, embedder_key, limit=20, video_ids=None, sampler=None, question=None, strategy=None, chunk_ids=None, structured=None) -> list[dict]
ArgumentIs
vectorThe query's vector.
queryThe query's text, for full-text search.
embedder_keyOnly compare units with this embedder.
limitUnits to return (the search's candidates).
video_idsOnly these videos; None is all.
samplerOnly units whose sampler_id equals this.
questionOnly units whose question equals this.
strategyOnly units whose sampler equals this.
chunk_idsOnly these chunks (time windows already resolved).
structuredOnly units whose fields equal each value, or whose list contains it.

Return units best first, as dicts with video_id, chunk_id, sampler_id, sampler, question, content, structured, score, dense_rank (1 = best) and text_rank (or None). Only the order is used, not the scores.

search_aggregates(...)

search_aggregates(vector, query, embedder_key, level, limit=5, source_ids=None) -> list[dict]

Rank the units of one level stored under embedder_key, optionally only from source_ids. Return dicts with source_id, video_ids, aggregate_id, item_id, level, content, start_ts, end_ts, score, best first.

search_observations(...)

search_observations(vector, query, embedder_key, limit=20, video_ids=None, sampler=None, question=None, strategy=None, after=None, before=None, since=None, until=None, structured=None) -> list[dict]

Rank a live run's rows stored under embedder_key. The filters are those of search, plus after/before on media_ts and since/until on seen_at (ISO 8601 UTC strings). Return dicts with video_id, chunk_id, sampler_id, sampler, question, frame_index, media_ts, frames, description, structured, seen_at, score, dense_rank, text_rank, best first.

close()

Release connections. Called when a with block exits; safe to call more than once.

Complete example: SQLite

Grid, moment vectors and aggregate vectors in one SQLite file, searched by cosine similarity.

docs/pages/examples/custom_database.py
"""A database of your own: SQLite, holding the grid, the moment vectors and
the aggregate vectors, and searching both.

Fill in only the hooks you need. A write hook left out does nothing (that
artifact is not copied); a read hook left out raises `Unsupported`.

    python custom_database.py path/to/video.mp4
"""

import json
import math
import sqlite3
import sys

import vidra
from vidra import Database, LocalEmbedder, Models, OpenAI, aggregates
from vidra.video_rag import search, video_rag
from vidra.video_rag.samplers import Clip

vidra.configure(env_file=".env")


def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    return dot / ((math.sqrt(sum(x * x for x in a)) * math.sqrt(sum(y * y for y in b))) or 1.0)


def matches(fields, wanted):
    """Every wanted field equal to its value, or a list holding it."""
    return all(fields.get(k) == v or (isinstance(fields.get(k), list) and v in fields[k])
               for k, v in wanted.items())


class SQLite(Database):
    name = "sqlite"                         # what run.problems calls it

    def __init__(self, path="vidra.sqlite"):
        self.db = sqlite3.connect(path)
        self.db.executescript("""
            create table if not exists chunks (video_id text, chunk_id int,
                start_ts real, end_ts real, primary key (video_id, chunk_id));
            create table if not exists units (video_id text, chunk_id int,
                sampler_id text, sampler text, question text, content text,
                structured text, embedder text, vector text,
                primary key (video_id, chunk_id, sampler_id, embedder));
            create table if not exists sources (source_id text primary key, video_ids text);
            create table if not exists aggregate_units (source_id text, aggregate_id text,
                item_id text, level text, content text, start_ts real, end_ts real,
                embedder text, vector text);
        """)

    # ---- writes: called as each stage finishes, with the file's JSON as a dict

    def write_timeline(self, video_id, document):
        self.db.execute("delete from chunks where video_id = ?", (video_id,))
        self.db.executemany("insert into chunks values (?, ?, ?, ?)",
                            [(video_id, c["chunk_id"], c["start_ts"], c["end_ts"])
                             for c in document["chunks"]])
        self.db.commit()

    def write_embedded(self, video_id, document):
        self.db.executemany(
            "insert or replace into units values (?, ?, ?, ?, ?, ?, ?, ?, ?)",
            [(video_id, u["chunk_id"], u["sampler_id"], u["sampler"], u["question"],
              u["content"], json.dumps(u["structured"]), document["embedder"],
              json.dumps(u["vector"]))
             for u in document["units"] if u.get("vector")])
        self.db.commit()

    def write_source(self, source):
        self.db.execute("insert or replace into sources values (?, ?)",
                        (source["source_id"], json.dumps(source["video_ids"])))
        self.db.commit()

    def write_aggregate_units(self, source_id, units, embedder_key):
        # Defining this hook is what makes a run embed summaries and chapters.
        ids = {u["aggregate_id"] for u in units}
        self.db.executemany("delete from aggregate_units where source_id = ? "
                            "and aggregate_id = ?", [(source_id, a) for a in ids])
        self.db.executemany(
            "insert into aggregate_units values (?, ?, ?, ?, ?, ?, ?, ?, ?)",
            [(source_id, u["aggregate_id"], u["item_id"], u["level"], u["content"],
              u.get("start_ts"), u.get("end_ts"), embedder_key, json.dumps(u["vector"]))
             for u in units])
        self.db.commit()

    # ---- reads: needed only to search through this database

    def video_ids(self):
        return [row[0] for row in self.db.execute("select distinct video_id from chunks")]

    def spans(self, video_id):
        return [(start, end) for start, end in self.db.execute(
            "select start_ts, end_ts from chunks where video_id = ? order by chunk_id",
            (video_id,))]

    def search(self, vector, query, embedder_key, limit=20, video_ids=None, sampler=None,
               question=None, strategy=None, chunk_ids=None, structured=None):
        rows = []
        for (vid, chunk, sampler_id, sampler_name, asked, content, fields,
             vec) in self.db.execute(
                "select video_id, chunk_id, sampler_id, sampler, question, content, "
                "structured, vector from units where embedder = ?", (embedder_key,)):
            fields = json.loads(fields)
            if ((video_ids and vid not in video_ids)
                    or (sampler and sampler_id != sampler)
                    or (question and asked != question)
                    or (strategy and sampler_name != strategy)
                    or (chunk_ids and chunk not in chunk_ids)
                    or (structured and not matches(fields, structured))):
                continue
            rows.append({"video_id": vid, "chunk_id": chunk, "sampler_id": sampler_id,
                         "sampler": sampler_name, "question": asked, "content": content,
                         "structured": fields,
                         "score": cosine(vector, json.loads(vec))})
        rows.sort(key=lambda r: r["score"], reverse=True)
        return [{**r, "dense_rank": rank, "text_rank": None}
                for rank, r in enumerate(rows[:limit], start=1)]

    def search_aggregates(self, vector, query, embedder_key, level, limit=5,
                          source_ids=None):
        sources = {sid: json.loads(vids)
                   for sid, vids in self.db.execute("select * from sources")}
        rows = []
        for sid, agg, item, lvl, content, start, end, _, vec in self.db.execute(
                "select * from aggregate_units where embedder = ? and level = ?",
                (embedder_key, level)):
            if source_ids and sid not in source_ids:
                continue
            rows.append({"source_id": sid, "video_ids": sources.get(sid, [sid]),
                         "aggregate_id": agg, "item_id": item, "level": lvl,
                         "content": content, "start_ts": start, "end_ts": end,
                         "score": cosine(vector, json.loads(vec))})
        rows.sort(key=lambda r: r["score"], reverse=True)
        return [{**r, "dense_rank": rank, "text_rank": None}
                for rank, r in enumerate(rows[:limit], start=1)]

    def close(self):
        self.db.close()


models = Models(vlm=OpenAI("gpt-6-luna"), llm=OpenAI("gpt-6-luna"),
                embedder=LocalEmbedder())

with SQLite("data/vidra.sqlite") as database:
    run = video_rag(sys.argv[1], "data/out", sampler=Clip(), models=models,
                    database=database)
    moments, notes = search("a person at a counter", run.video_id,
                            models=models, database=database)
    for m in moments:
        print(f"chunk {m.chunk_id}: {m.start_ts:.1f}-{m.end_ts:.1f}s")

    d = run.folder
    video = aggregates.record(timeline=d / "timeline.json",
                              descriptions=d / "descriptions.json")
    told = video.excerpt(answers={"clip": ["summary"]})
    aggregates.aggregate(out=d / "aggregates", models=models, database=database,
                         summary=told, chapters=told)
    for hit in aggregates.search("the opening", level="span", models=models,
                                 database=database):
        print(f"{hit['aggregate_id']} {hit['item_id']}: {hit['start_ts']}-{hit['end_ts']}s")
