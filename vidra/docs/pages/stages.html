Stages

The steps video_rag() runs, and how to call each one on its own with all of its settings.

Each stage is a module under vidra.video_rag with three kinds of function:

FunctionTakesDoes
the stage's own name: media.media, audio.audio, ...file pathsreads its inputs, writes one output file, returns a receipt (Produced)
a verb: split, listen, detect, timeline, ingest, apply, answer, look, encodedocuments already in memorythe same work, returning the document; reads and writes no file
loada pathreads the stage's output back, typed

The file function is the verb with a read before and a write after, so both run the same checks. Its receipt has .video_id, .component, .artifacts ({name: path}), .stats and .skipped. Below, D is a video's folder; the stage-by-stage recipe runs every stage.

from pathlib import Path
from vidra.video_rag import audio, boundaries, cut, describe, embed, glance, media, video

1. media

Reads the file's streams and makes the video's folder. Writes media.json.

media.media(source, into, video_id=None, on_conflict="new", name=None, recorded_at=None) -> Produced
ArgumentDefaultMeaning
sourcerequiredThe video file.
intorequiredThe folder holding one folder per video.
video_idfilename stemThe folder's name.
on_conflict"new"When a different file holds the id: new, replace or refuse (Video ids).
name, recorded_atfrom the fileDisplay name and recording time (a datetime or ISO 8601 string).
made = media.media("shop.mp4", "data/out")
D = Path(made.stats["folder"])        # data/out/shop
made.video_id                         # the id actually used

media.split(path, video_id=None, name=None, recorded_at=None) returns the Media without writing, and media.load(path) reads media.json. A file with no video or audio stream raises media.UnusableMedia; a taken id with on_conflict="refuse" raises media.VideoIdTaken.

2. audio

Transcribes the whole soundtrack and identifies the speakers. Writes transcript.raw.json: words, segments and speaker turns with their times, before chunking. Requires vidra[audio].

audio.audio(media, out, transcriber="whisper", diarizer="pyannote", model=None, language=None, vad_filter=None, compute_type=None, device=None, diarizer_model=None, exclusive=None) -> Produced
ArgumentDefaultMeaning
mediarequiredPath to media.json.
outrequiredWhere to write transcript.raw.json.
transcriber"whisper"whisper (faster-whisper), or stub (placeholder text, for tests).
diarizer"pyannote"pyannote, or none: every segment keeps speaker: null.
model"small"Whisper's model: tiny, base, small, medium, large-v3, ...
languagedetectedSpoken language, e.g. "en"; detected if not given.
vad_filterTrueSkip stretches without speech. Without it, Whisper can produce text for silent passages.
compute_typefloat16 on a GPU, int8 on the CPUWhisper's precision.
devicecuda, else the CPUFor both models. Whisper has no mps.
diarizer_model"pyannote/speaker-diarization-3.1"pyannote's pipeline. Gated: the first download needs HF_TOKEN from an account that accepted its terms.
exclusiveTrueResolve overlapping speech so each word has one speaker.
audio.audio(D / "media.json", D / "transcript.raw.json",
            model="medium", language="en", diarizer="pyannote")

A setting the chosen backends don't use is refused, for example language with transcriber="stub". A near-silent soundtrack is recorded as silent without loading a model.

audio.listen(media, ...) takes a Media and returns the RawTranscript. audio.load(path) reads one back.

3–4. boundaries

Two steps: evidence finds where the content changes and writes cuts.json (except under uniform), and boundaries turns the changes into chunks and writes timeline.json.

evidence

boundaries.evidence(out, policy, media=None, raw_transcript=None, stride=5, threshold=27.0, detect_width=320, silence_s=0.65) -> Produced
ArgumentDefaultPolicyMeaning
outrequiredWhere to write cuts.json.
policyrequireduniform (does nothing), scene, vad, speaker.
mediascenePath to media.json.
raw_transcriptvad, speakerPath to transcript.raw.json.
stride5sceneScore every Nth frame. Higher is faster but finds more false cuts.
threshold27.0sceneThe change score needed for a cut, on PySceneDetect's content scale. Lower finds more cuts.
detect_width320sceneFrames are scaled to this width before scoring.
silence_s0.65vadA pause at least this long is a cut.

A setting the policy doesn't use is refused (boundaries.EVIDENCE_SETTINGS lists them). Scene scores are saved in cuts.json, so a new threshold needs no second decode:

boundaries.evidence(D / "cuts.json", "scene", media=D / "media.json", stride=5)

for row in boundaries.calibrate(D / "cuts.json"):          # nothing is decoded
    print(row["threshold"], row["cuts"], row["rate"], row["median_gap_s"])

boundaries.retune(D / "cuts.json", D / "cuts.json", threshold=35.0)   # rewrite the cuts
  • calibrate(cuts, thresholds=None) returns how many cuts each threshold would give, as rows of threshold, cuts, rate (cuts per scored frame) and median_gap_s. cuts is a path or a Cuts; thresholds defaults to a range suited to the detector.
  • retune(cuts, out, threshold) rewrites the cuts at a new threshold.

boundaries

boundaries.boundaries(media, out, policy="uniform", cuts=None, chunk_s=20.0, min_s=5.0, max_s=None) -> Produced
ArgumentDefaultMeaning
mediarequiredPath to media.json.
outrequiredWhere to write timeline.json.
policy"uniform"As in evidence.
cutsnonePath to cuts.json; required by every policy but uniform.
chunk_s20.0The chunk length for uniform, and the default ceiling.
min_s5.0Shorter chunks merge into a neighbour.
max_schunk_sLonger chunks are split into equal parts.
boundaries.boundaries(D / "media.json", D / "timeline.json", policy="scene",
                      cuts=D / "cuts.json", min_s=10, max_s=40)
grid = boundaries.load(D / "timeline.json")
len(grid), grid.spans[0]            # 12, (0.0, 19.93)

A final chunk shorter than a quarter of chunk_s is merged into the one before it. A min_s greater than max_s is refused.

To work in memory, detect(policy, media=None, transcript=None, stride=5, threshold=27.0, detect_width=320, silence_s=0.65) returns the Cuts (None for uniform), and timeline(media, policy="uniform", cuts=None, chunk_s=20.0, min_s=5.0, max_s=None) returns the Timeline:

m = media.split("shop.mp4")
grid = boundaries.timeline(m, "scene", cuts=boundaries.detect("scene", media=m))

boundaries.POLICIES maps each policy to what its evidence reads: None, "video" or "audio".

5. video

Decodes the picture once, offers frames to each sampler and stores the ones kept. Writes manifest.json and the JPEGs in store/. See Samplers.

video.video(media, timeline, out, store=None, sampler=None, per_second=1.0, store_scope="sampled", prune_store=False, on_progress=None) -> Produced
ArgumentDefaultMeaning
media, timelinerequiredPaths to media.json and timeline.json.
outrequiredWhere to write manifest.json.
storenoneThe folder for the kept frames. Without it, no frames are saved and describe has nothing to read.
samplerUniform()A sampler object or a list of them, each with its own settings.
per_second1.0Frames offered to the samplers per second of video.
store_scope"sampled""sampled" stores kept frames; "decimated" stores every offered frame.
prune_storeFalseDelete frames this manifest doesn't use; otherwise the store keeps growing across runs.
on_progressnoneCalled with a Progress after each chunk.
from vidra.video_rag.samplers import Clip, Objects

video.video(D / "media.json", D / "timeline.json", D / "manifest.json", store=D / "store",
            sampler=[Objects(vocabulary=["cart", "basket"], confidence=0.4,
                             max_per_chunk=4), Clip()])

Samplers and questions are checked before decoding starts. A file without a readable video stream raises video.UnreadableSource.

video.ingest(media, timeline, sampler=None, per_second=1.0, frames=None, store_scope="sampled", on_progress=None) takes a Media and Timeline, writes frames into frames (a FrameStore, or None), and returns the Manifest. video.load(path) reads one back.

frames

video.frames decodes a file as the video stage does, for your own model: the frames in order, rotated upright. With per_second, it yields only the first frame of each 1/per_second interval.

video.frames(path, per_second=None) -> Iterator[Frame]
for frame in video.frames("shop.mp4", per_second=2):
    boxes = detector(frame.image)          # your own model, on BGR pixels
    print(f"{frame.media_ts:.1f}s", len(boxes))

Each video.Frame has index (its position among all decoded frames), media_ts (seconds), pts and image. For a live stream, use live.frames.

The frame store

video.FrameStore(root, quality=95, fmt="jpg") writes each kept frame once into root as a JPEG named by its position in the video. Views such as crops are stored beside their frame as <index>.<sampler>.<n>.jpg.

store = video.FrameStore(D / "store")
plan = video.ingest(media.load(D / "media.json"), boundaries.load(D / "timeline.json"),
                    "clip", frames=store)

recreate

Rebuilds every stored frame from the manifest and the video, and can compare the result byte for byte with an existing store:

video.recreate(*, manifest, video, out, verify=None, force=False, quality=95) -> dict
ArgumentMeaning
manifestPath to manifest.json.
videoThe video file it was built from.
outWhere to write the frames.
verifyAn existing store to compare with.
forceRebuild even if the video's size, rate or frame count differ from the manifest (otherwise video.Mismatch); differences go in problems.
qualityJPEG quality the store was written at; must match for an identical rebuild.
done = video.recreate(manifest=D / "manifest.json", video="shop.mp4",
                      out="rebuilt", verify=D / "store")
done["named"], done["written"], done["missing"], done["problems"]
done["verified"]["identical"]          # True when every frame matches

A missing video file raises video.MissingVideo. Views made by a sampler are not rebuilt; done["views_not_rebuilt"] counts them.

6. cut

Splits the raw transcript into chunks by each word's midpoint and writes transcript.json. No model runs, so a new grid never re-runs Whisper.

cut.cut(timeline, raw_transcript, out) -> Produced
cut.cut(D / "timeline.json", D / "transcript.raw.json", D / "transcript.json")
spoken = cut.load(D / "transcript.json")
spoken.chunks[3]["text"], spoken.chunks[3]["structured"]["speakers"]

cut.apply(timeline, raw) does the same in memory. Chunks without speech are kept with empty text, so chunk ids match the other files.

7. describe

Sends each chunk's frames to the vision model once per sampler and question. Writes descriptions.json. Calls run concurrently, up to the model's concurrency.

describe.describe(manifest, timeline, store, out, previous=None, vlm=None, samplers=None, limit=None, max_output_tokens=None, on_progress=None, max_images=None) -> Produced
ArgumentDefaultMeaning
manifest, timelinerequiredPaths to manifest.json and timeline.json.
storerequiredThe frame folder video wrote.
outrequiredWhere to write descriptions.json.
previousnoneEarlier descriptions.json (usually out); current answers are reused.
vlmOpenAI()The vision model.
samplersallDescribe only these answer ids, such as ["clip:text"]; the others are copied from previous.
limitnoneThe most new calls to make in this run. A later run with previous= continues where it stopped. Must be at least 1.
max_output_tokens8000The token limit for one answer, reasoning included. Too low a limit cuts off structured answers. Changing it re-describes everything.
on_progressnoneCalled with a Progress after each call, in completion order.
max_imagesnoneRefuse the run, before any call is made, if a single call would send more than this many images (frames and views).
describe.describe(D / "manifest.json", D / "timeline.json", D / "store",
                  D / "descriptions.json", previous=D / "descriptions.json",
                  vlm=OpenAI("gpt-6-luna"), limit=20)

said = describe.load(D / "descriptions.json")
answer = said.chunks[0]["samplers"]["clip"]
answer["description"]           # the prose
answer["structured"]            # the fields: {"setting": ..., "people": [...], ...}

A frame with views is sent as its labelled views; image_count is added when images and frames differ in number. Frames are read only from the store: a missing frame raises describe.StoreUnavailable, an unreachable model describe.DescriberUnavailable.

If any call fails, the whole run fails and none of its new answers are written.

describe.answer(manifest, timeline, frames, vlm=None, samplers=None, limit=None, existing=None, max_output_tokens=None, on_progress=None, max_images=None) does the same in memory; existing is an earlier Descriptions to reuse. Adding and listing questions is covered in Questions.

ask: images you hold

Asks one question about images you already have, such as crops from a tracker, with no manifest, grid or store. Nothing is written.

describe.ask(images, question, *, timestamps=None, vlm=None, max_output_tokens=None) -> Description
ArgumentDefaultMeaning
imagesrequiredJPEG or PNG bytes, image file paths, or BGR arrays (what video.frames yields), in time order.
questionrequiredAny question in describe.questions(); its shape decides the fields (Questions).
timestamps0, 1, 2, ...Each image's time in seconds, shown to the model beside it.
vlmOpenAI()The vision model.
max_output_tokens8000The token limit for the answer, reasoning included.
said = describe.ask([crop_1, crop_2, crop_3], "yolo", timestamps=[12.0, 14.5, 17.0],
                    vlm=OpenAI("gpt-6-luna"))
said.summary                    # the prose
said.fields["people"]           # [{"appearance": ..., "clothing": ..., "gender": ...}]

It returns a describe.Description with summary and fields. Bad arguments are refused before the call. describe.ask_async is the coroutine version, for a running event loop or for several questions at once:

answers = await asyncio.gather(*(describe.ask_async(t.crops, "yolo", vlm=vlm)
                                 for t in tracks))

7b. glance

Embeds each chunk's kept frames directly with a visual embedder, alongside describe or instead of it. Writes glances.json, in embedded.json's format, which search reads like any other index.

glance.glance(manifest, timeline, store, out, previous=None, visual_embedder=None, samplers=None, batch=16, on_progress=None) -> Produced
ArgumentDefaultMeaning
manifest, timelinerequiredPaths to manifest.json and timeline.json.
storerequiredThe frame folder video wrote.
outrequiredWhere to write glances.json.
previousnoneEarlier glances.json (usually out); units whose images are unchanged keep their vectors.
visual_embedderrequiredA VisualEmbedder; there is no default. Search must use the same one.
samplersallOnly these sampler runs, e.g. ["clip"]; a name the manifest lacks is refused.
batch16Units per call to the model.
on_progressnoneCalled with a Progress after each batch.
from vidra import LocalVisualEmbedder, Models

seen = LocalVisualEmbedder("google/siglip2-base-patch16-224")
glance.glance(D / "manifest.json", D / "timeline.json", D / "store",
              D / "glances.json", previous=D / "glances.json", visual_embedder=seen)

index = glance.load(D / "glances.json")
index.embedder                    # "local:google/siglip2-base-patch16-224:768:mean:images"
index.units[0]["sampler_id"]      # "clip:image"
index.units[0]["structured"]      # {"frames": [12, 15, 19]}

search("a forklift by the door", "shop", models=Models(visual_embedder=seen), database=db)

Each chunk and sampler run gives one unit: the frames the run kept there and their views. Its sampler_id is <run>:image, its question is image (reserved) and its content is empty. A unit over the model's max_images is refused before any image is read.

Units are stored under the model's key plus :images (glance.space_of(visual_embedder)), so they never overwrite text vectors. Search ranks frames and text separately and merges the rankings (see search). glance.look(manifest, timeline, frames, visual_embedder=None, samplers=None, previous=None, batch=16, on_progress=None) does the same in memory.

Unlike describe, glance gives no fields, no full-text search and nothing for the aggregates. Image models match appearance well but actions, negation, counts and on-screen text poorly. Prefer SigLIP 2 to CLIP ViT-B/32: fusing a weak image model with text search can rank worse than text alone.

8. embed

Turns every answer and every chunk's transcript into a unit of text and embeds it. Writes embedded.json: units and vectors under the embedder's key.

embed.embed(out, descriptions=None, transcript=None, previous=None, timeline=None, embedder=None, batch=64, on_progress=None) -> Produced
ArgumentDefaultMeaning
outrequiredWhere to write embedded.json.
descriptions, transcriptnonePaths to embed from; name at least one.
previousnoneEarlier embedded.json (usually out); unchanged units keep their vectors.
timelinenonePath to timeline.json, recorded as the units' grid.
embedderOpenAIEmbedder()The embedder; search must use the same one.
batch64Texts per embedding call.
on_progressnoneCalled with a Progress after each batch.
embed.embed(D / "embedded.json", descriptions=D / "descriptions.json",
            transcript=D / "transcript.json", previous=D / "embedded.json",
            timeline=D / "timeline.json", embedder=LocalEmbedder())

index = embed.load(D / "embedded.json")
index.embedder                    # "local:BAAI/bge-small-en-v1.5:384"
index.units[0]["content"], len(index.units[0]["vector"])

A unit's text is the answer's prose followed by its fields, with the keys sorted, so the same answer always produces the same text.

embed.encode(descriptions=None, transcript=None, previous=None, embedder=None, batch=64, on_progress=None) works in memory and returns a list of embed.Unit: video_id, chunk_id, sampler_id, sampler, question, content, structured, vector. An unreachable embedder raises embed.EmbedderUnavailable.

The whole chain in memory

The in-memory functions can be chained without an output folder. Only the frames are written, to the store you pass:

from vidra import LocalEmbedder, Stub

m = media.split("shop.mp4")
raw = audio.listen(m)
grid = boundaries.timeline(m, "scene", cuts=boundaries.detect("scene", media=m))
store = video.FrameStore("frames/shop")
plan = video.ingest(m, grid, "clip", frames=store)
spoken = cut.apply(grid, raw)
said = describe.answer(plan, grid, store, vlm=Stub())
units = embed.encode(descriptions=said, transcript=spoken, embedder=LocalEmbedder())
