Custom samplers

Write your own rule for which frames to keep, and use it anywhere a built-in sampler works.

Quick example

Subclass Sampler, give it a name, and implement propose, which returns whether to keep a frame. Then pass an object of it, as you would Clip():

from vidra import Sampler
from vidra.video_rag import video_rag
from vidra.video_rag.samplers import Clip

class Bright(Sampler):
    """Keep a frame when it is brighter than `level` (0-255)."""
    name = "bright"

    def __init__(self, level=120, min_interval_s=0.0, max_per_chunk=None,
                 sampler_id=None, prompts=None):
        super().__init__(min_interval_s, max_per_chunk, sampler_id, prompts)
        self.level = level

    def propose(self, frame, chunk_local_index):
        return frame.image.mean() > self.level

    def config(self):
        return {**self._base_config(), "level": self.level}

video_rag("x.mp4", "data/out", sampler=[Bright(level=140, prompts=["overview"]), Clip()])

The video is decoded once and each offered frame goes to both samplers. The frames bright keeps are described with the overview question and stored under the answer id bright:overview, next to clip's answers.

The Sampler class

class Sampler(min_interval_s=0.0, max_per_chunk=None, sampler_id=None, prompts=None)
MemberIs
nameClass attribute. The sampler's name, used in answer ids (motion:overview). Lowercase letters, digits, _ and -, and not a built-in sampler's name.
propose(frame, chunk_local_index)Required. Return True to keep the frame. frame.image is the picture as a BGR array (borrowed, so copy anything you keep), frame.media_ts its time in seconds and frame.index its number in the video. chunk_local_index counts the offered frames in this chunk, from 0.
on_reset(chunk_id)Called at the start of each chunk, before its first frame. Reset the sampler's state here.
config()The settings recorded in the manifest, as plain JSON: {**self._base_config(), ...your settings}.
last_score()Optional. A number recorded with each kept frame, such as how much the picture changed.
views(frame)Optional. The images the model is shown for a kept frame; by default, the frame itself (see below).
__init__(...)Your settings first, then min_interval_s, max_per_chunk, sampler_id and prompts, which are passed to super().__init__.
Base settingIs
min_interval_sSmallest gap, in media seconds, between two kept frames.
max_per_chunkAt most this many kept frames per chunk; None for no limit.
sampler_idThe run's key in the manifest; None is name.
promptsThe questions asked about the kept frames; none means the question named after the sampler.

What the base class does

  • A frame within min_interval_s of the last kept frame, or beyond max_per_chunk, is rejected before propose is called. Otherwise the frame is kept when propose returns True.
  • The first frame of every chunk is always kept. propose is still called for it and its return value ignored, so you can use that call to set a reference.
  • Frames arrive one at a time; a sampler cannot look ahead or go back. This is why the same sampler works on files and on live streams.

State between frames

Store anything the next frame needs, such as a reference image or a count, on self, and reset it in on_reset. Each run uses a shallow copy of your object: a model loaded in __init__ is shared between runs, while attributes assigned in on_reset belong to one run. Assign new objects in on_reset rather than modifying a list or dict created in __init__, which all copies share.

def on_reset(self, chunk_id):
    self.reference = None              # each chunk starts afresh

def propose(self, frame, chunk_local_index):
    small = frame.image[::8, ::8].mean(axis=2)
    if self.reference is None:         # the chunk's first frame: kept anyway
        self.reference = small
        return True
    moved = abs(small - self.reference).mean() / 255
    if moved >= self.threshold:
        self.reference = small         # compare with the last kept frame
        return True
    return False

Showing the model more than the frame

By default, the model is shown each kept frame unchanged. To show something else, return a list from views(frame). View.FRAME stands for the frame itself; any other View is an image you made from it, such as a crop, an enlargement or a copy with faces blurred. Leave out View.FRAME to send only your images.

View(image, label, meta={})
FieldIs
imageA BGR array made from frame.image. A slice of it is fine, because views are saved immediately.
labelRequired. Text shown to the model before the image, after the frame number, as in Frame 2, the till, enlarged 2x -- t=81.00s:.
metaPlain JSON recorded with the view in the manifest, such as a box or a scale.
import cv2
from vidra import Sampler, View

class Till(Sampler):
    name = "till"

    def __init__(self, box, **base):
        super().__init__(**base)
        self.box = box                          # (x1, y1, x2, y2) of the till

    def propose(self, frame, chunk_local_index):
        return chunk_local_index % 5 == 0

    def views(self, frame):
        x1, y1, x2, y2 = self.box
        till = cv2.resize(frame.image[y1:y2, x1:x2], None, fx=2, fy=2)
        return [View.FRAME, View(till, "the till, enlarged 2x", {"box": list(self.box)})]

    def config(self):
        return {**self._base_config(), "box": list(self.box)}
  • views is called once for each kept frame, right after propose.
  • Views are saved next to the frame as <index>.<sampler>.<n>.jpg and listed under views in the frame's manifest record. A sampler that returns only [View.FRAME] records nothing extra.
  • The recorded views are part of the manifest's fingerprint, so changing them re-describes the affected answers. Put the settings that shape them in config() as well.
  • Each view adds an image to the model call. A chunk's kept frames are described in one call, so five frames with three views each send twenty images. describe.describe(..., max_images=) refuses a run that would exceed a limit before making any call.
  • video.recreate does not rebuild views. It reports how many it skipped as views_not_rebuilt; re-run the video stage to make them again.

yolo and objects use this for crops.

Using it

Pass the object in the sampler list of video_rag, video_rag_live or video.video, alongside built-in samplers. Each sampler may appear only once, so two objects with the same name are refused. Put all of a sampler's questions on one object, as in prompts=["overview", "safety"].

Questions

Without prompts, a sampler asks the question with its own name, which doesn't exist for a new sampler. Give it prompts=[...], or add a question with its name using describe.add_question. Otherwise the run is refused before decoding starts.

Reading its output elsewhere

Search and the aggregates read the output files, not the class, so a run's output can be read in a process that doesn't have the class, or on a machine where its question is not defined.

Complete example: motion

Keeps a frame when enough of the picture has changed since the last kept frame, by comparing downscaled frames, with no model. It only suits fixed cameras, since with a moving camera nearly every frame changes. The script runs it on a file and on a live stream.

docs/pages/examples/custom_sampler.py
"""A sampler of your own: keep a frame when enough of the picture moved.

Cheap -- no model, a downscaled difference -- and for fixed cameras only. On
shop CCTV, threshold 0.10 kept 10-18% of decimated frames (CLIP at its default
keeps 13-18% there) and ignored sensor noise, which 0.05 and below did not. A
moving camera or an edited film changes nearly every pixel every second: it
kept 30-76% even at 0.45. Use `clip` for those.

    python custom_sampler.py path/to/video.mp4
"""

import sys

import numpy as np

import vidra
from vidra import Folder, LocalEmbedder, Models, OpenAI, Sampler
from vidra.video_rag import video, video_rag, video_rag_live
from vidra.video_rag.samplers import Uniform

vidra.configure(env_file=".env")


class Motion(Sampler):
    """Keep a frame when the share of pixels that changed since the last kept
    frame reaches `threshold`."""

    name = "motion"                     # stored with its answers: motion:overview

    def __init__(self, threshold=0.10, scale=8, min_interval_s=0.0,
                 max_per_chunk=None, sampler_id=None, prompts=None):
        super().__init__(min_interval_s, max_per_chunk, sampler_id, prompts)
        self.threshold, self.scale = threshold, scale
        self._last_score = None

    def on_reset(self, chunk_id):
        self.reference = None           # every chunk starts afresh

    def propose(self, frame, chunk_local_index):
        # frame.image is BGR and borrowed: copy anything kept past this call.
        small = frame.image[::self.scale, ::self.scale].mean(axis=2)
        if self.reference is None:
            self.reference, self._last_score = small.copy(), None
            return True                 # the first frame of a chunk is kept anyway
        moved = float((np.abs(small - self.reference) > 25).mean())
        self._last_score = moved
        if moved >= self.threshold:
            self.reference = small.copy()
            return True
        return False

    def last_score(self):
        return self._last_score         # recorded beside each kept frame

    def config(self):
        # What the manifest records about the run: plain JSON only.
        return {**self._base_config(), "threshold": self.threshold, "scale": self.scale}


source = sys.argv[1]
models = Models(vlm=OpenAI("gpt-6-luna"), embedder=LocalEmbedder())

# Each object carries its own settings and questions, built-in or not.
run = video_rag(source, "data/out", use_audio=False, models=models,
                sampler=[Motion(threshold=0.10, prompts=["overview"]),
                         Uniform(every_n=10, prompts=["overview"])],
                database=Folder("data/out"))
manifest = video.load(run.folder / "manifest.json")
for sid in ("motion", "uniform"):
    print(sid, "kept per chunk:",
          [c["samplers"].get(sid, {}).get("frame_count", 0) for c in manifest.chunks])

# The same class on a live stream.
live = video_rag_live(source, "data/out", video_id="motion-live",
                      sampler=Motion(prompts=["overview"]), models=models)
print(live.observations, "answers from motion:overview, lag", live.lag_s)
