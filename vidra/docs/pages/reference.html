File formats, errors, storage locations and hardware.

Documents

Every document is a JSON object with document (its type), version and video_id fields, and is what the matching write_<artifact> database hook receives. Times are in seconds. Each stage's load function reads its document back as a typed object.

media.json

FieldIs
pathThe file's path when read.
container_formatContainer format.
duration_sThe container's duration.
videoThe picture stream, or null: index, codec, rate (frames per second), time_base, width, height, frames, duration_s.
audioThe soundtrack, or null: index, codec, rate (samples per second), channels, duration_s.
sourceA fingerprint of the file's contents, which tells a moved file apart from a different one.
nameDisplay name; the filename unless given.
recorded_atRecording time (ISO 8601) from tags unless given, or null.

transcript.raw.json

FieldIs
segmentsWhisper's utterances: start, end, text, speaker.
wordsEach word: start, end, text, speaker.
turnsDiarization's turns: speaker, start, end.
speakersThe speaker labels, e.g. ["SPEAKER_00"].
modelTranscriber, diarizer, settings, detected language.
trackThe decoded audio: rate, duration_s, samples, rms, peak, silent.
statsCounts (segments, words, speakers, turns, speech seconds) and timings.

cuts.json

FieldIs
cutsThe boundary times.
sourcevideo or audio.
detectorcontent for the scene detector, or the policy name.
paramsSettings used (threshold, stride, ...).
scoresPer-frame scores (metric, stride, at, values) for retune and calibrate, or null.
statsFrames read and scored, timing, cuts found.

timeline.json

FieldIs
chunksThe grid: chunk_id, start_ts, end_ts, contiguous.
policyuniform, scene, vad or speaker.
derived_fromvideo, audio, grid (arithmetic), or combined.
paramsSettings used (min_s, max_s, ...); for a combination, combined places each video.
fingerprintA hash of the grid. Every later document records it, so mismatched grids can be detected.
duration_s, chunk_countThe grid's length and size.

manifest.json

FieldIs
chunksPer chunk: chunk_id, decimated_frames (frames offered), and samplers: {sampler_id: {frame_count, frames}}, each frame with index (its file in the store), media_ts, chunk_local_index, pts.
sourceWhat was decoded: path, container, duration, stream properties. video.recreate checks against it.
configDecimator, sampler settings (with prompts) and frame store settings.
statsframes_decimated, frames_sampled (picks), stored_frames (files), stored_mb, timing.
timeline_fingerprint, manifest_fingerprintHashes of the grid and of this sampling run.

transcript.json

FieldIs
chunksPer chunk, silent ones included: chunk_id, text, word_count, turns (speaker, start, end, text), structured ({"speakers": [...]}).
modelCarried from the raw transcript.
statsChunks, chunks with speech, words, words outside the grid, speakers.
timeline_fingerprintThe grid it was cut on.

descriptions.json

FieldIs
chunksPer chunk: chunk_id and samplers: {answer_id: answer}. Each answer has sampler, question, description (the prose), structured (the fields), frame_count, frame_indexes, elapsed_s.
modelThe VLM: name, params and prompts ({question: hash}); compared for reuse.
statsDescribed, skipped (reused), chunks, timing.
timeline_fingerprint, manifest_fingerprintThe grid and sampling described.

embedded.json

FieldIs
embedderThe embedder's key: the vector space.
unitsEach unit: chunk_id, sampler_id (answer id or transcript), sampler, question, content, structured, text_hash, characters, vector.
count, samplersHow many units, and which answer ids.
timeline_fingerprintThe grid.

Aggregate answers

One file per answer, named by its id (summary.json; entities:people as entities.people.json):

FieldIs
aggregate_idsummary, entities:people, or with a label sentiment~spoken.
tierfree, local or llm.
payloadThe answer; keys per aggregator on Aggregates.
inputs_fingerprintA hash of the text it read.
statsabout, model (key), inputs, version (definition hash), read_chars.

Saved inputs: an excerpt holds selection, the timeline, the rows (one per chunk with text) and the answers that contributed; a sightings file holds the profile, selection, field_name, identity keys, the timeline, the mentions (each chunk_id, sampler_id, field, index, signature, entry) and, when the profile reads it, the transcript of the chunks mentioned.

Receipts: Produced

Returned by every stage and aggregator:

FieldIs
video_idThe video id used (media may mint a new one).
componentWhich stage or aggregator.
artifacts{name: path} of what was written.
statsIts headline numbers.
skippedWhat didn't run, e.g. ["evidence"] under uniform.

JSON Schemas are in db/json/; python -m vidra.shared.contracts.schemas --check checks them.

The data root is data/ in a checkout of the repository, otherwise ~/.vidra. configure() overrides environment variables, which override the defaults; VIDRA_DATA and VIDRA_WEIGHTS are not read from .env. Folders starting with _ are not treated as videos.

VIDRA logs to the vidra logger and configures no handlers. Call logging.basicConfig(level=logging.INFO) to see each stage; failed database writes are logged as warnings.

Hardware

PyTorch models (CLIP, YOLO, the local embedders and pyannote) use CUDA if available, then mps, then the CPU. Whisper uses CUDA or the CPU. GLiNER, the sentiment model and the text detector always run on the CPU. Approximate time per minute of video, on a mid-range laptop GPU and on its CPU:

WorkGPUCPU
Whisper small + pyannote~6 s~1.5 min
clip, yolo and objects~25 s~50 s
text~12 s (CPU only)

Describe calls run concurrently, up to the model's concurrency (8 by default), so a run takes roughly as long as its slowest call.

  • The mps backend has not been tested. If pyannote fails on a Mac, set PYTORCH_ENABLE_MPS_FALLBACK=1 before starting Python. Intel Macs can't install the required PyTorch version.
  • Whisper on an NVIDIA GPU needs CUDA 12's cuBLAS and cuDNN, which vidra[audio] installs. Without them the run is refused before it starts; pass device="cpu" to use the CPU instead.
  • Decoding 3 hours of 720p at one frame per second takes about 2 minutes.

Checking an install

  • python -m vidra.shared.contracts.schemas --check checks that the JSON Schemas match the document types.
  • video.recreate(..., verify=store) rebuilds the frames and compares them byte for byte with the store (see recreate).
  • In a checkout, python docs/pages/build.py --check checks that the docs cover every public function and parameter, and --run a.mp4 b.mp4 runs every example with free stand-in models.
